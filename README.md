"Steady Door" — a program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it: the judge sets one verdict down for a breath, the lamp is warm, the page is patient, and the words wait, steady as a door held open.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (254 characters, deterministic — the same bytes on every run). No network, no input.
